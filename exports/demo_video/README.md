# Demo film production: Coach's Eye

Sources for `Coach_Eye_Final_Hackathon_Demo.mp4` (2:34.7, 1920×1080, 30 fps). The film is published on YouTube. Heavy media stays local and out of Git (see `.gitignore`).

| Tracked here | What it is |
|---|---|
| `FINAL_SCRIPT_AND_STORYBOARD.md` | Shot-by-shot script: timestamps, narration, on-screen text, footage source times, sound |
| `project/index.html` | The HyperFrames composition, generated by `project/tools/build.py` |
| `project/tools/build.py` | One timing table for footage cuts, narration, captions, clicks and camera moves; writes `index.html`, `final/captions.srt` |
| `project/tools/tts.py` | Kokoro (local TTS) synthesis of `project/narration.json` |
| `project/tools/finalize.py` | Two-pass loudness normalisation (−15 LUFS) and remux |
| `project/SPEC.md`, `STORYLINES.md`, `REVIEW.md` | Spec, the storylines considered, and the review / QA note |
| `audio/vo_word_timings.json` | Word timings of each narration line (Whisper), used for captions |
| `final/captions.srt`, `final/thumbnail_1280x720.jpg`, `final/PUBLISHING.md` | YouTube subtitles, thumbnail, and the title/description/tags |

**Local only, not tracked:**
- `raw/`: constant-frame-rate crops of the two screen recordings;
- `project/assets/`: the media the composition uses;
- `audio/`: narration WAVs;
- `renders/`;
- `.venv-tts/`;
- `final/*.mp4`.

The original recordings (`~/Desktop/Screen Recording 2026-11-07 at 3.22.34 AM.mov` and `… 3.28.19 AM.mov`) are untouched; their SHA-1s are in `raw/originals.sha1`.

**Rebuild** (needs the local media):
```
cd project
python3 tools/build.py
npx hyperframes@0.9.19 render --fps 30 --quality delivery --crf 12 --video-frame-format png --no-best-effort -o ../renders/out.mp4
python3 tools/finalize.py ../renders/out.mp4 ../final/Coach_Eye_Final_Hackathon_Demo.mp4
```
