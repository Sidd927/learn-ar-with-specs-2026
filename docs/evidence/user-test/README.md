## Decision rules (agreed before testing; don't change them after seeing results)
- **Thresholds:** at least 60% rounded up (2 of 3, 3 of 4, 3 of 5) for each of: purpose without explanation; Knees difference; Chest difference; why the viewpoint changes; returning to the demonstration alone. If any is missed, the results go to the owner before the video.
- **Heels rule:** if 2 or more participants answer Partly or No on Heels, the results go to the owner for a design decision before the video (`../heels-decision/`).

## File here
- `P1.md` … `P5.md`: one completed sheet each (verbatim answers, including unsuccessful ones).
- `SUMMARY.md`: the raw-count table from the observation sheet, which thresholds were met or missed, and whether the Heels rule was triggered.

Report raw counts only. These are formative prototype decision criteria, not statistical validation or evidence that the product improves learning.
