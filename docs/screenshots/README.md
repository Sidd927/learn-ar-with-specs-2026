# Screenshot index

All images are real captures of the running Lens in the **Lens Studio 5.24.1 preview** (device SPECS 27, Interactive input), taken on 31 Oct 2026 from the final build. None are Scene-viewport renders or edited images.

Unless noted, each shot is taken from the user's start position (preview camera reset to the origin). Phase shots were opened directly on that phase with the controller's capture hook (`startPhase`/`startAngle`). That hook is off by default and isn't used in normal launches.

> **Note (branch `feature/coach-eye`):** `01`–`12` were captured from the `main` build. On the branch, the cue card also shows the "Compare a common mistake" row (visible in `13`–`15`). Recapture `02`–`11` if the branch is merged.
