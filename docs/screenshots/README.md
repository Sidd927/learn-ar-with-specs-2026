# Screenshot index (final build)

**Status: FINAL for build `83e71bc`** (branch `feature/coach-eye`), captured on 1 Nov 2026. The earlier set (31 Oct 2026, pre-build copy and 3.4 cm buttons) is archived, unchanged, in `archive-2026-10-31/`. Use only this folder for the README, Devpost and the video plan.

All images are real captures of the running Lens in the **Lens Studio 5.24.1 preview** (device SPECS 27, Interactive input), taken with the Preview panel capture tool at 1399 × 1590 px. None are Scene-viewport renders or edited images; `07` is a crop of `04` (nothing else is changed). They show preview behaviour only, not SPECS hardware.

Each shot is taken from the user's start position (preview camera not moved). Phase, angle and comparison shots were opened with the controller's capture hook (`startPhase` / `startAngle` / `startFault`); `11` used `startPhase` 5, which autoplays to the end. The hook was reset to normal launch (−1 / empty) and saved afterwards.
